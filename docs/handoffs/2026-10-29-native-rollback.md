## 사용자가 원했던 것과 실패에서 배운 점

원했던 것은 기존 웹에서 자연스럽게 움직이던 손·손목·팔 동작에 네이티브 추적 입력을 연결하는 것이었습니다. 처음에는 별도 관절 방향 변환을 작성하고 손목·팔만 일부 재사용해 의도에서 벗어났습니다. 이후 실제 main.js를 재사용해도 사용자가 원하는 화면이 나오지 않았습니다.

계산 방향 단위 테스트, 3D 파일 생성, 코드 공유, 소프트웨어 렌더러 화면, 빌드/Lint 통과는 **실제 손의 자세가 자연스럽다는 검증이 아니었습니다.** 어느 단계/버전/좌표가 원인인지 현재 확정하지 못했습니다. 단순히 MediaPipe 탓 또는 특정 변환 하나 탓으로 단정하지 않습니다.
