# 네이티브 FBX 저장 — 2026-10-29

## 요청과 범위 정정

사용자는 “glb말고 fbx파일로도 만들수있게”를 **Android 앱**에 요청했습니다. 앞선 웹 전용 구현은 대상 오해였습니다. 웹 PR #3을 닫았으며 main에 병합하지 않았습니다. 해당 브랜치는 참고 이력일 뿐 배포 버전이 아닙니다.

원본 MediaPipe 측정 앱에 **FBX 저장**을 추가합니다. 거절된 Quest 손·팔·WebView·웹 리깅을 다시 넣지 않습니다. 기존 JSON 저장은 유지합니다. Android versionCode 8 / 0.8-native-fbx-export.

## 구현

- 측정 시작 → 측정 중지 → FBX 저장 → Android 파일 선택기로 .fbx 저장.
- 기록의 원본 MediaPipe world 좌표와 타임스탬프를 사용합니다. 각 손 21개 관절을 계층으로 연결하고 위치 애니메이션을 기록합니다.
- 자체 Kotlin FBX 7.4 binary writer. 새 앱 의존성·모델·권한·서버 변환 없음. 저장 시에만 별도 작업 스레드로 생성합니다.
- x,-y,-z 한 번의 축 변환과 미터 단위 메타데이터를 사용합니다.
- 검출되지 않은 손은 뿌리 스케일 0으로 표시하고, 가림 전후 위치를 채우거나 예측하지 않습니다. 같은 측면 중복 검출은 저장 단계에서 점수가 높은 것 하나만 선택합니다.
- 추적 모델·검출 크기·전처리·임계값·CPU/GPU 선택·화면 관절점은 변경하지 않습니다. 추적 정확도나 FPS 개선을 주장하지 않습니다.
- 앱 코드 크기는 export 코드만큼 증가하며 새 모델 다운로드나 매 프레임 추론 증가는 없습니다.

## 중요한 한계

**손 메시 없는 원본 관절 위치 뼈대 파일**입니다. 본 회전·손가락 비틀림을 푼 고정 길이 게임 리그, Quest 손, 스킨드 메시 FBX가 아닙니다. 원본 추정 좌표의 잡음과 뼈 길이 변화도 보존합니다. 각 손의 상대 world 좌표이므로 두 손의 절대 배치나 카메라 기준 이동을 복원한 것이 아닙니다. 한 카메라에서 보이지 않는 깊이·가림을 정확히 복원했다고 표현하지 마세요.

실제 SM-S931N에서 설치·파일 저장·Blender/Unity/Unreal 수동 확인은 아직 하지 않았습니다. CI 통과는 휴대폰 사용자 승인이나 추적 정확도 검증이 아닙니다.
