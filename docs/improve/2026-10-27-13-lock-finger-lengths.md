# 13. 처음 제대로 잡힌 손의 손가락 길이를 끝까지 고정

## 요청
2026-10-27 사용자: "처음에 손모양이 제대로 만들어지면 그 손의 손가락 길이나 모양은 끝까지 고정되어야함"

## 지금 상태
- 화면·GLB의 손 모델 뼈 길이는 원래 고정(모델 길이). 바뀌는 건 깊이 추정(lift.js) 쪽:
  매 프레임 MediaPipe 3D가 주는 뼈 길이를 표준 길이의 0.8~1.25배 안에서 그대로 씀.
  같은 손가락 길이가 프레임마다 최대 50% 달라지고, 사진 속 길이가 같아도 깊이(굽힘)가 달라짐.
- 기준선: 채점 전용 jump 200, fjump(표시 합) 56, pstill 18 / 개발 jump 5847, fjump 3799, pstill 832.

## 예상 (고치기 전에 씀)
손가락이 곧게 보이는 프레임 10번으로 그 손 뼈 길이를 정하고 이후 고정하면:
채점 전용 jump 200 -> 190 이하, pstill 18 -> 16 이하, fjump 5% 안. 개발 jump 3% 정도 줄어듦.

## 결과
| 시도 | 채점 전용 jump / fjump / pstill / gsw | 개발 jump / fjump / pierce |
|---|---|---|
| 기준 | 200 / 56 / 18 / 17 | 5847 / 3799 / 59 |
| 1. 곧게 보인 10번(사진 길이 85%+) world 길이 중앙값으로 고정 | 200 / 56 / 18 / 17 (채점 영상에선 고정이 한 번도 안 일어남) | 5447 / 3385 / 99 |
| 2. world 길이 안 쓰고 표준 길이(+사진으로 배운 성장)만 | 198 / 50 / 17 / 25 | 5738 / 5250 / 178 |
| 3. 시도 1을 75%로 완화(개발 영상 기준으로 고름) | 206 / 65 / 18 / 17 | 5643 / 4502 / 54 |
모두 되돌림. 예상(jump 190 이하, pstill 16 이하) 못 미침, 채점 전용은 같거나 나빠짐.

## 결론
- 화면·GLB의 손가락 길이는 이미 처음부터 끝까지 고정(GLB 손가락 뼈는 회전만 저장, exportGlb.js).
  사용자가 보는 "모양이 바뀜"은 길이가 아니라 깊이 모호(굽힘 vs 카메라 쪽으로 편 손가락) 때문.
- 깊이 추정 쪽 길이 고정은 효과 없음. MediaPipe world 길이가 프레임마다 흔들려도 그게 깊이 단서 역할을 함.
- 이 방향 더 손대면 도돌이표. 다음은 손톱/주름 사진 모델(손가락 끝 방향을 픽셀로)과 양손 충돌.
