# 개선 2: 엄지를 표지 위에 납작하게 편 손모양 데이터 부족

## 1. 채점용 점수 (v76, 개선 1 되돌린 상태)
jump 303, fjump 198, gsw 21, flip 9, 자신 없음 207 (hidden 134, facing 73)

## 2. 유형
손가락 튐(그대로 1위). 개발용 영상에서 튐의 51%(324/635)가 "가려진 손가락 + 맞는 손모양 없음" 프레임.
그 324 모두 영상 전체로 고른 손모양이 보이는 관절과 16~45도 어긋남.
자신 없는 프레임 목록 1위: 책을 들고 네 손가락이 가려지고 엄지만 보임. 이때 읽힌 엄지는
뿌리(CMC)가 뒤로 젖혀진 납작한 엄지(-20~-35도)인데, 책 손모양 데이터의 엄지는 모두 앞으로 굽음(+5~+40도).
주의: 읽힌 값이 관절 범위 끝(-30도)에 붙어 있어 일부는 MediaPipe 오독일 수 있음.
상수 조정(NONE_COST)은 이미 4~128로 시험한 방향이라 도돌이표 위험 -> 데이터로 접근.

## 3. 고치기 전 예상
- 수정: "책·판 위에 엄지를 납작하게 펴 누르고 네 손가락으로 받치기" 손모양 묶음(엄지 뿌리 -10/-20도, 관절 범위 안) 추가, 기존과 6도 이상 다른 것만.
- 채점용(영상 1개, 책이 아닐 수 있음): fjump 198 -> 185~198 (0~7%), hidden 134 -> 110~134. 효과 작을 것으로 예상.
- 개발용 book_turn: 자신 없는 hidden 프레임 감소 예상.
- 채점용이 나빠지면 되돌림.

## 4. 수정
후보 18개를 만들었지만 기존과 6도 이상 다른 것은 3개뿐(엄지만 다른 모양은 손 전체 기준으로 거의 같음).

## 5. 다시 채점
채점용: fjump 198 -> 198, jump 303 -> 303, 자신 없음 207 -> 207 (변화 0).
개발용: 자신 없음 5279 -> 5268, fjump 4595 -> 4597, jump 5206 -> 5204.
예상(채점용 0~7% 감소)의 아래쪽 끝, 즉 효과 없음.

## 6. 결과
되돌림. 이 유형(가려진 손가락 튐)을 손모양 데이터 몇 개로 줄이기는 어려움.
가려진 손가락은 정답이 안 보이므로, 다음은 가상 데이터(정답 있음)로 이 유형을 직접 재는 쪽이 나음.
