# 21. 손바닥 방향(거울 선택)에 큐브 표 넣기 (2026-10-27)

**요청.** 손톱 면은 끄고 모든 손가락 큐브는 유지. 손바닥 방향 결정에 큐브 표를 넣어 보기. 손톱 정보를 쓸지는 내가 판단.

**확인한 것 (개발용 seed11, 976장).**
- 손톱 면 읽기로는 거울 두 자세를 구분할 수 없어요. 두 자세는 깊이만 뒤집힌 모양이라, 손바닥이 카메라를 향하는 정도(법선 z)가 똑같아요. 다른 건 기울어진 방향이에요. 그래서 손톱은 쓰지 않았어요.
- 대신 각 뼈가 카메라 쪽으로 얼마나 향하는지(along)를 써요. 두 자세로 각각 들어 올린 뒤 손가락 15개 뼈의 along이 큐브 읽기와 얼마나 맞는지 비교해요.
- 큐브 표만으로 고르면 맞는 비율 74%(668/906)예요. 지금 규칙은 95%(861/906)라서 표가 규칙을 대신할 수는 없어요.
- 큐브 표가 아주 확실할 때만(비용 차 200 이상) 덮어쓰면 고침 18, 망침 11이에요. 개발용 관절 각도 오차 15.74 -> 15.63, 뒤집힘 13 -> 14.

**예측 (채점 전에 씀).** 비용 차 200, 뼈 15개.
- seed10: 17.34 -> 17.25 안팎 (-0.1)
- 양손 채점분: 17.67 -> 17.6 안팎
- 뒤집힘 ±1
- 실제 held-out 영상: 사진이 없어 영향 없음 (확인 불가)
- 앱 무게: 촬영 분석 때 프레임마다 lift를 2번 더 돌려야 해요 (lift는 가벼움, 손당 1ms 안팎 예상)

## 결과 (채점 전용)
| | seed10 (한손) | 양손 채점분 |
|---|---|---|
| 관절 각도 오차 | 17.34 -> 17.50 (나빠짐) | 17.67 -> 17.80 (나빠짐) |
| 손바닥 방향 중앙값 | 16.5 -> 15.8 | 19.1 -> 18.8 |
| 뒤집힘(>90도) | 14 -> 16 | 10 -> 8 |

예측(-0.1)과 반대로 주 지표가 나빠졌어요. 규칙대로 **되돌림** (앱 코드는 바꾸지 않았고 커밋도 없음).
원인 추정: 큐브 along은 손가락 굽힘과 손바닥 기울기가 섞인 값이에요. 손가락이 굽은 정도를 모르는 상태에서 손바닥 방향만 판단하는 데 쓰면, 굽힘이 다른 자세를 손바닥 거울로 잘못 설명하는 경우가 생겨요.
다시 시도하지 않을 것: 손톱 면으로 거울 고르기(두 자세의 법선 z가 같아서 원리상 불가), 큐브 along 단독 표.
