# 손가락끼리 뚫고 지나감 (2026-10-26, 사용자 영상 pencil_fidget_21-40.glb)

## 1. 점수
새 표시 pierce: 풀린 손에서 서로 다른 손가락 뼈(캡슐, 반지름 7~9.5mm)가 8mm 넘게 겹친 프레임.
이 영상 (911 손 프레임): pierce 604 (엄지-중지 241, 엄지-검지 178, 엄지-약지 49, 중지-약지 67, 검지-중지 59).

## 2. 유형
엄지가 다른 손가락 속을 지나감 (pierce의 78%).

## 3. 고치기 전 예상
- 수정: fit.js 손가락 맞추기에 "다른 손가락 캡슐 안으로 못 들어감" 벌점. 네 손가락을 먼저 맞추고(서로도 피함), 엄지는 마지막에 이미 맞춘 손가락을 피해서 맞춤.
- 이 영상 pierce 604 -> 100 이하.
- 실제 채점용 jump 196 / fjump 33: 5% 넘게 나빠지면 되돌림 (엄지가 밀려나며 튈 수 있음).
- 가상 채점 오차 (seed2 합계): 20.50 근처 유지 (+-0.3).
- 무게: 손가락 하나 맞출 때 거리 계산 18쌍 x 반복 -> 프레임당 약 1ms 미만 예상.
