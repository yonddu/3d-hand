# 개선 4: 그림에서 곧게 뻗은 손가락이 굽게 나옴 (사용자 신고: 양손 가운뎃손가락)

## 1. 점수 (v77, 같은 영상 중복 제외)
새 지표 bentpic = 그림에서 곧고 충분히 긴 손가락인데 결과의 둘째+셋째 마디 굽힘이 60도 넘음.
실제 채점용(w2): bentpic 13, fjump 33, jump 196, swap 0.  개발용: bentpic 431, fjump 434, jump 1438, swap 8.
가상 채점용 관절 각도 오차 20.50도.

## 2. 유형
사용자 신고 영상 clasp_same_14-10.glb 8.7~9.7초: MediaPipe 2D는 가운뎃손가락이 곧게 뻗었다고 보는데 3D 값은 접혔다고 봄.
결과에서 반쯤 굽음.

## 3. 고치기 전 예상
- 수정: 그림에서 곧고 긴 손가락은 "주먹 안에 숨은 손가락"으로 보지 않음 (끝 두 마디가 데이터 손모양을 따르지 않고 보이는 대로).
- 개발용 bentpic 431 -> 약 250, 채점용 13 -> 약 8.
- 가상 채점용 오차 20.50 -> 20.2~20.5 (작은 개선 또는 그대로).
- 튐(fjump)은 약간 늘 수 있음(채점용 33 -> 33~45). 채점용 영상이 나빠지면 되돌림.

## 4~6. 수정, 재채점, 결과
수정 후: 채점용 bentpic 13 -> 22, fjump 33 -> 62, jump 196 -> 248 (나빠짐). 개발용 bentpic 431 -> 428 (거의 그대로).
예상과 다름: 굽어 보이는 원인이 "숨은 손가락 판단"이 아니었음. 되돌림.
