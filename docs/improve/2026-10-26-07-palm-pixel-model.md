# 손바닥/손등 픽셀 모델 (2026-10-26, 첫 학습)

## 만든 것
- tools/synthSkin.js: 학습용 렌더에서만 MIT 손 모델에 손톱, 마디 주름(손바닥 쪽 이중선, 손등 쪽 주름), 손금 3줄, 밝은 손바닥 색을 칠함. 앱 화면과 GLB 저장에는 안 들어감.
- tools/palm/crops.py: MediaPipe 점으로 손 잘라내기 (손목→가운뎃손가락 뿌리가 위, 64x64).
- tools/palm/train.py: 작은 CNN (3x3 stride2 4층, 46,737개 가중치, float16 91KB), JAX.
- src/palmFace.js: 앱용 순수 JS (잘라내기 + 추론, PC node 3.9ms/손), sideFromPicture (손바닥/손등 + 엄지 쪽 → 왼/오).
- 녹화 옵션 "녹화에 손 부분 작은 사진 저장" (기본 꺼짐, 5프레임마다, 1분 약 1.5MB).

## 데이터
